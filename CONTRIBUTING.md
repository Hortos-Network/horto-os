# Contributing


Thank you for your interest in contributing to Horto-OS!

We deeply believe in the power of open source communities, and that belief has shaped this project from the very beginning.

Horto-OS is still at an early stage and under active development. We are sorry that we review a lot of pull requests at the moment.
Our focus is on verifying the integrity of the scripts and ensuring that it meets our standards.
However, contributing code to this repository is far from the only way to help. There are many other ways to get involved:


- Identify and report issues or bugs in GitHub Discussions:
  - Upvote discussions that you would like to bring to the team's attention. We are a very small team and may not be able to reply to every post, but we monitor them and consider them when allocating resources.
- Contribute to the ecosystem:
  - Create a guide to install more apps on Horto-OS.
  - Create a guide to install Horto-OS on your own hardware.
  - Write blog posts and how-to guides about Horto-OS.
  - Answer questions and help other members of the community.

Horto-OS is designed to be deeply customizable. We do not believe that packages in the official repository are inherently more important than packages created by the community. You may consider this repository an idea, an official showcase, and a source of inspiration, but not a mandate from us.
