# Informations

This stack provides files for a basic deployment of a rkvoice-stream TTS model,
including a wqyolming wrapper.
Unfortunately, it is much more complex than the Piper TTS model, so we ditched in
favour of the Piper TTS model.

> [!info]
> The models are not included in this stack see [here](https://github.com/suharvest/rkvoice-stream).
